# seed 데이터 출처 및 성격

이미지는 전부 **직접 도안한 합성 샘플**입니다. 실제 개인정보가 없고,
저작권 문제 없이 리포에 커밋·재배포할 수 있습니다.

| 파일 | 성격 | 용도 |
|---|---|---|
| `arc_d2_front.jpg` | D-2 외국인등록증 앞면 (스캔 품질) | OCR 정상 케이스 |
| `arc_d2_front_photo.jpg` | 앞면, 촬영본 (기울임·조명·노이즈) | OCR 난이도 케이스 |
| `arc_d2_back_1.jpg` | 뒷면 (스캔 품질) | 체류자격·만료일·체류지 |
| `arc_d2_back_photo_1.jpg` | 뒷면, 촬영본 | OCR 난이도 케이스 |
| `passport_d2.jpg` | 여권 정보면 (MRZ 포함) | MRZ 파서 정상 케이스 |
| `mrz.txt` | MRZ 2줄 원문 | 파서 단위 테스트 |
| `profile.json` | 기대 프로필 | Mock 서버가 읽음 |
| `tasks.json` | 기대 Task Graph | Mock 서버가 읽음 |

## MRZ

체크섬(여권번호·생년월일·만료일·개인번호·복합)이 전부 유효하게 계산되어 있습니다.
파서는 체크섬 검증까지 통과해야 정상입니다.

```

M123456788VNM9901018M3005202<<<<<<<<<<<<<<08
```
