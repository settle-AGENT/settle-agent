- 여권번호: C4567890 (만료 2031-06-15)

## 데모 타임라인

D-2 는 **등록 전**, E-9 는 **등록 후** 상태다. 두 단계를 모두 덮는다.

```
[D-2]
2026-08-15  입국 (여권만 보유)
2026-08-18  서비스 접속
2026-09-05  등록증 발급
2026-11-13  외국인등록 법정기한 (D-87)
2027-02-28  체류만료

[E-9]
2026-06-25  입국
2026-07-01  등록증 발급
2026-09-23  외국인등록 법정기한 (입국 +90일)
2029-06-30  체류만료
```

`tasks_e9.json` 은 손으로 쓴 것이 아니라 `planner.build_task_graph` 를
2026-09-19 기준으로 돌려 받은 출력이다. 과제가 넷뿐인 것은 E-9 의
`work_activity` 가 `allowed: false` 라 목록에서 빠지기 때문이다.

## 주의

- 실제 타인의 신분증 이미지는 어떤 경우에도 리포에 넣지 않습니다.
- E-9 등록증 앞뒷면은 팀에서 직접 도안한 것입니다. 실제 E-9 등록증처럼
  **뒷면에 근무처(PLACE OF EMPLOYMENT) 칸**이 있습니다 — 취업 자격의 등록증은
  체류지와 근무처를 함께 적습니다. 여권은 그 페르소나에 맞춰 HTML 로 그린 뒤
  Chromium 으로 렌더했습니다.
- 이 앞면을 CLOVA OCR 에 실제로 태워 본 결과가 `ai/tests/test_e9.py` 에
  그대로 들어 있습니다. 거기서 성명이 통째로 비는 버그를 찾았습니다 —
  이름 정규식이 대문자 두 낱말 이상만 이름으로 봤고, SITI 는 한 낱말이었습니다.
- 처음에는 `SAMPLE` 워터마크와 "SYNTHETIC SPECIMEN" 띠를 넣었다가 뺐습니다.
  이름 추출 정규식이 "대문자 두 낱말 이상"을 사람 이름으로 보는데(`arc.py`
  의 `_RE_NAME`), 워터마크의 영문 대문자가 거기 걸려 실제 성명 대신 뽑힐 수
  있었습니다. **OCR 고정물은 카드에 실제로 인쇄되는 것만 담아야 합니다.**
  합성물이라는 사실은 이 파일이 기록합니다.
- 정부 공개 견본 이미지를 추가로 쓸 경우 이 파일에 출처를 명시합니다.
- `ocr_cache/`는 CLOVA 응답 캐시입니다. 커밋하지 마세요 (.gitignore 권장).
